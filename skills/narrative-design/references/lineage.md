# Lineage and distribution boundary

This independently authored implementation is inspired by Marcus Andrews' marketing
Narrative Design, which builds on Andy Raskin's strategic narrative work. His public [2020 article](https://marcusandrews.substack.com/p/why-narrative-design-will-replace)
discusses strategic story design, and his [2022 LaunchNotes interview](https://www.launchnotes.com/blog/narrative-design-with-pendos-director-of-product-marketing-marcus-andrews)
explains investigating audience change, its consequences and a useful adaptation
before introducing supporting tools. It also discusses difficulty and product help.
The five working labels here organize that reasoning; this is not an official
course, workbook, transcript or endorsed implementation.

The author also consulted private practitioner guides and examples while
developing the method. They are not included here, and no rights in them are
claimed. The package
contains newly written operating instructions and illustrative examples. MIT applies
to that authored implementation only; it does not license another author's course,
framework text, trademarks or source corpus.

The explicit review contract, historical challenge, positioning-first readiness,
claim/evidence separation, bounded research-return loops and dependency-aware
revision are implementation decisions. The situation-led fallback is an explicit
reframe when a historical change is unsupported, not a claim that every input
supports the original change-led sequence. Useful methods and frameworks retain
their attribution; no framework invention is claimed.

Each skill remains independently usable.
